ABS — Appointment Booking System

Online appointment booking for clinics, doctors' chambers, salons, consultants and any service business. Built on Laravel, with an admin panel, a public booking page, a customer panel, and online payments through bKash, Nagad, SSLCommerz, Stripe and PayPal.

Thank you for your purchase. This page explains how to install, set up and use the system. If something is not covered here, see support.

Features

Several businessesEach business has its own branches, timezone, currency, staff, services and settings.
No double bookingA doctor's time booked by one person cannot be booked by anyone else, even when two people press "Confirm" at the same moment.
Smart time slotsWorking hours, breaks, time off, holidays, buffers, minimum notice and booking window are all respected.
CalendarColour per staff member, drag and drop to reschedule, quick status actions, click an empty slot to book.
Customer panelBooking history, details, reschedule, cancel, print slip, pay online, download prescriptions and reports.
Find bookingAnyone can open their booking with the booking number and phone number, with an optional SMS code.
Online paymentsbKash, Nagad, SSLCommerz, Stripe and PayPal, set up per business from the admin panel.
Payments and refundsDeposits, partial payments, cash at the counter, discounts, refunds and invoices.
NotificationsE-mail on every change and reminders before the visit. Optional SMS.
ReportsBookings, revenue, staff utilisation and cancellations, with CSV export.
RolesOwner, Manager, Receptionist and Staff. A staff member sees only their own appointments.
Mobile friendlyThe booking page and customer panel are designed for phones first.

Installation

1. Upload and install packages

Upload the app and abs folders to your server, side by side. Then:

cd app
cp .env.example .env
composer install --no-dev --optimize-autoloader
php artisan key:generate

2. Create a database and edit .env

Create an empty MySQL database, then set:

APP_NAME="Appointment Booking"
APP_URL=https://booking.example.com
DB_DATABASE=abs
DB_USERNAME=your_user
DB_PASSWORD=your_password
QUEUE_CONNECTION=database
METHEME_HOME_ROUTE=abs.dashboard
APP_URL must be exactly the address people use (https, with or without www). Booking links are signed and fail with any other address.

3. Create the tables

php artisan migrate --force
php artisan db:seed --force
php artisan vendor:publish --tag=metheme-assets
php artisan abs:install
php artisan storage:link
php artisan optimize

Optional demo data (a clinic with 6 doctors and sample bookings), only on an empty system:

php artisan abs:install --clinic-demo

4. Web server

Point the domain's document root to app/public. Make app/storage and app/bootstrap/cache writable by the web server user.

# Nginx (inside the server block)
root /var/www/app/public;
index index.php;
location / { try_files $uri $uri/ /index.php?$query_string; }
location ~ \.php$ { include fastcgi_params; fastcgi_pass unix:/run/php/php8.3-fpm.sock; fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name; }

Apache works with the included public/.htaccess (enable mod_rewrite).

5. Sign in

Open https://your-domain/login with admin@mestiaque.com / p@ssword.

Change this password immediately (top-right menu → Profile), or create your own admin and delete this account. The default password is public.

First setup

  1. Users & Roles → Users: create accounts for the owner, receptionists and doctors/staff.
  2. Business → Businesses → Add: name, web address (slug), timezone, currency, phone and address.
  3. Business → Members: add the users to the business as owner, manager, receptionist or staff.
  4. Catalog & Staff → Categories and Services: duration, price, buffer time.
  5. Catalog & Staff → Staff: add each doctor, choose their services and link their user account.
  6. Open each staff member's Hours page and set the weekly schedule (see Staff hours).
  7. Business → Booking Settings: approval, time-slot step, minimum notice, how far ahead, cancellation rules, payment mode.
  8. Configuration → Mail Configuration: your SMTP details.
  9. Optional: payment gateways.
  10. Share your booking link: https://your-domain/book/your-slug.

Cron and queue

Add one cron entry (crontab -e):

* * * * * cd /var/www/app && php artisan schedule:run >> /dev/null 2>&1

Keep a queue worker running with Supervisor:

[program:abs-worker]
command=php /var/www/app/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
user=www-data
stopwaitsecs=3600

The scheduler sends reminders (abs:send-reminders) and releases unpaid time slots (abs:expire-holds). The Diagnostics page in the admin panel shows whether both are working.

Reports

Staff hours

Open Catalog & Staff → Staff → Hours. Add one or more time ranges per weekday (for example 10:00–13:00 and 17:00–20:00), breaks, and days off. Use 24:00 for "until midnight". Business-wide holidays are under Business → Holidays.

Payment gateways

Open Business → Payment Gateways. For each gateway: enter the merchant keys, choose Sandbox or Live, switch it on and press Test connection. Then set Booking Settings → Payment mode.

GatewayKeysRegister at the gatewayRefunds
bKashApp key, App secret, Username, PasswordNothingFrom the admin panel

PayPalClient ID, Secret, Webhook IDWebhook URL shown on the pageFrom the admin panel

Payment modes

  • Pay later: pay at the counter; staff record the payment.
  • Online optional: customers may pay online now or later.
  • Full payment required / Deposit required: the time is held until payment; unpaid holds are released automatically.

Safety

  • A payment is marked paid only after the server checks with the gateway and the amount matches.
  • bKash and Nagad accept BDT only, so they are hidden for businesses in other currencies.
  • If a payment arrives after the booking was cancelled or expired, it is refunded automatically.
Before going live, make one sandbox payment and one refund with your own merchant account. If you change APP_KEY, the saved gateway keys must be entered again.

Notifications

E-mails are sent when a booking is made, confirmed, rescheduled, cancelled or paid, and as a reminder before the visit (reminder time is set in Booking Settings). Set SMTP in Configuration → Mail Configuration. To send SMS as well, set up metheme's SMS gateway and add ABS_SMS_NOTIFICATIONS=true to .env.

Updating

Back up the database and .env first.

php artisan down
# replace the files with the new version (keep .env and storage/)
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan abs:install
php artisan optimize
php artisan queue:restart
php artisan up

Troubleshooting

ProblemSolution
"No free time" on every dayThe staff member has no hours, the service is not assigned to them, or the booking window is too short.
E-mails are not sentStart the queue worker and set SMTP.
Reminders are not sentAdd the cron entry.
"Invalid signature" / 403 on a booking linkAPP_URL differs from the browser address. Fix it and run php artisan optimize.
Admin pages look unstyledphp artisan vendor:publish --tag=metheme-assets and clear the browser cache.
A gateway is not offeredIt is switched off, the currency is not BDT (bKash/Nagad), or the payment mode is "Pay later".

FAQ

Can two people book the same doctor at the same time?

No. The system locks the doctor's schedule while saving, so only one booking wins. The other person is asked to pick another time.

Can I run several clinics or branches?

Yes. Add several businesses, and branches inside each one. Staff see only the businesses they belong to.

Which timezone is used?

Each business has its own timezone. Times are stored in UTC and shown in the business's timezone, including daylight-saving changes.

Can I change the colours or texts?

Yes. Views are in abs/src/resources/views. Publish or copy them to customise.

Is there a web installer?

No. Installation is done with the commands above. This avoids a public setup page on a live site.
